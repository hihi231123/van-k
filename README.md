# Судебный реестр задолженности — дело № 15-LA-2026

Статический сайт для отслеживания задолженности Семёнова Ивана Эдуардовича (Сямёнау) в лаки стрелах.

## Правила расчёта
- Начальная задолженность: 15 лаки стрел.
- Срок возврата: 30 ноября 2026 года включительно.
- Первое удвоение: 1 декабря 2026 года.
- Далее сумма удваивается первого числа каждого месяца.
- Формула: 15 × 2^N, где N — число наступивших ежемесячных удвоений.

Сайт автоматически рассчитывает сумму по локальной дате устройства при открытии страницы. Данные вручную вводить не требуется.

## Публикация через GitHub Pages
1. Откройте Settings в репозитории.
2. Перейдите в Pages.
3. В разделе Build and deployment выберите Deploy from a branch.
4. Выберите ветку main и папку /(root), затем нажмите Save.
5. После публикации сайт будет доступен по адресу https://hihi231123.github.io/van-k/.

Проект не использует сервер или базу данных.
